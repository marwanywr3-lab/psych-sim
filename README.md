# محاكي الطبيب النفسي — إصلاحات الأولوية العالية والمتوسطة

هذه نسخة نشر مستقلة مبنية على ZIP الذي قدمه المستخدم.

الإصلاحات: حماية الحفظ بين التبويبات، تعديل أو إلغاء الرسائل الفاشلة، رفض الحفظ غير المتسق، وحجز وقت العودة عند إنهاء أعمال اليوم. لم يُنفذ تعديل تكرار جلب النماذج منخفض الأولوية.

للنشر: يجب وضع index.html و.nojekyll ومجلد assets كاملًا في جذر الفرع المنشور. احتفظ بمجلد scenes داخل assets وبالخطوط داخل assets. لا ترفع الملفات كلها مسطحة في الجذر.

المصدر الأصلي غير مرفق. التعديل على نسخة النشر موثق وقابل لإعادة الإنشاء بواسطة build-priority-fixes.cjs خارج هذه الحزمة. الحفظ القديم يُقرأ بإصدار مراجعة صفري، وتُحفظ المراجعات الجديدة تلقائيًا. يُستحسن إعادة تحميل تبويبات النسخة القديمة قبل مواصلة اللعب.

اختبار الاتصال الفعلي وجودة Gemini يحتاجان مفتاح اختبار؛ الاختبارات المرفقة مع التسليم تستخدم محاكاة للردود.
